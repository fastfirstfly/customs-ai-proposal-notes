# As-Is簡易版：輸入急増と審査・検査能力の制約

最終確認日：2026年10月14日

## 一言で表すと

**計算・解釈**：輸入許可件数が税関定員を大きく上回るペースで増加する中、審査・検査で発見された申告内容の誤り等はほぼ横ばいである。公開データだけで見逃しの増加は証明できないが、審査・検査能力が貨物量の増加に追いついていない可能性がある。

## 2. データから読み取れること

![輸入許可件数と審査・検査における非違発見件数の比較](../assets/charts/noncompliance-findings-per-import-permits.svg)

**計算・解釈**：

- 2019年から2025年の輸入許可件数：**約4.89倍**
- 同期間の税関定員：**約1.07倍**
- 2015〜2019年平均から2019〜2023年平均までの輸入許可件数：**約2.67倍**
- 同期間に対応する非違発見件数：**約2.6%減で、ほぼ横ばい**
- 輸入許可10万件当たりの非違発見件数：**約291.0件から約106.2件へ、約63.5%低下**

この比率は、輸入許可件数の増加に対して、審査・検査による発見実績が同じペースで増えていないことを示す。ただし、実際の違反率や見逃し率を直接示す「発見率」ではない。

## 3. As-Isとして置く仮説

**未検証の仮説**：輸入貨物の増加に対して、区分2・3の書類審査・貨物検査を担う人的・物的な処理能力の拡大が追いついていない可能性がある。明示的な件数制限がなくても、実務上処理可能な範囲に審査対象を絞らざるを得ず、一定のリスクがある申告でも十分な審査対象とならない可能性がある。

**計算・解釈上の注意**：審査官の人数に応じて審査区分判定に明示的な件数上限が設定されていることや、区分2・3の判定基準が処理能力に応じて調整されていることは、公開資料では確認できていない。

## 4. To-Beで解くべき課題

**計算・解釈**：既存の審査区分判定を前提とし、区分2・3の書類審査に処理余力を生み出す。特定の製品・システム構成を先に決めず、以下を満たす業務状態を目指す。

1. 担当者が申告内容と添付書類の重要情報・不整合・確認箇所を短時間で把握できること
2. 同じ人員で処理できる区分2・3の案件数または1件当たりの確認の深さを高められること
3. 創出した処理余力を、審査対象の拡大または高難度案件の詳細確認に配分できること
4. 正当な貨物の迅速な通関を阻害しないこと
5. 指摘の根拠と職員の判断過程を説明・検証できること
6. 処理時間、処理可能件数、追加確認・申告修正、非違発見等を段階的に測定できること

詳細は、[To-Be方針：区分2・3の書類審査に処理余力を生み出す](03-to-be-direction.md)を参照する。

## 5. 現時点で断定しないこと

- **計算・解釈**：「10万件当たりの非違発見件数が下がったため、実際の違反率も下がった」とは言えない。
- **計算・解釈**：「人手不足によって見逃しが64%増えた」とは言えない。
- **計算・解釈**：非違発見件数の低下には、実際の誤りの発生率、審査対象の選定、制度、データ活用、取締り強度の変化も影響し得る。
- **未検証の仮説**：見逃しの有無と規模を確認するには、審査率・検査率、無作為検査による違反率、審査担当人員、1件当たり処理時間などの追加データが必要である。

詳細な計算、資料間の数値差および限界は、[現在確認できる問題と、その背景に関するエビデンス](02-current-problems-evidence.md#42-申告誤り等の発見実績を輸入許可件数で規格化した参考指標)を参照する。
